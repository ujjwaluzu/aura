Something else on your mind? ↗
What does “unsigned beta” mean?

The installer has no trusted code-signing certificate. Windows may display an unknown-publisher or SmartScreen warning. This is an early public beta with clean-Windows testing still pending. Review the source and release notes before deciding to install.

Does Aura start with Windows?

Yes. On its first release launch, Aura enables startup for the current user. Disable this in Settings → General → Start Aura with Windows. Windows Startup apps can override this setting.

Do I need a Google account for music controls?

No. Windows browser media-session controls work independently. Start media in a supported browser, then select its session in Aura. Available controls depend on that session. Google sign-in and YouTube account/library access remain gated pending provider requirements.

What is WebView2, and do I need it?

Aura uses Microsoft's WebView2 Runtime to display its local interface. The installer requests the official runtime only if missing. You can also get it from Microsoft's WebView2 download page.

What data leaves my computer?

Clock, system metrics, preferences and browser media metadata stay local to Aura. Optional GitHub integration contacts GitHub and stores credentials protected by Windows DPAPI. Aura has no hosted app backend or telemetry. This website adds no tracking, login or cookies; GitHub Pages handles hosting requests under GitHub's privacy policy. Read the privacy policy for details.

Where can I report a problem?

Open an issue on GitHub with the beta version, Windows version and steps to reproduce. Remove personal data and credentials from screenshots and logs.
